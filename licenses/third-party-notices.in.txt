Source code

The libraries under the GNU LGPL (Qt and FFmpeg) are separate DLL files in
the program folder; you may replace them with your own compatible builds.
Their source code is available from the links below. In addition, for at
least three years after each calibly release, the author will provide the
exact source code of these libraries in the version shipped with that
release on request (open an issue at
https://github.com/mblees/calibly/issues).
